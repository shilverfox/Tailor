# Tailor v1 · 设计规格（评审草案）

## 设计意图

Tailor 是一套克制、安静、可触摸的纪念工具，而不是哀伤内容产品。界面以旧相册纸张的温度承载真实照片，信息和操作始终优先于情绪渲染。禁止彩虹、翅膀、天堂、拟人宠物语言及“复活”暗示。

## 基础视觉

| Token | 值 | 用途 |
|---|---:|---|
| Paper / `--paper` | `#F8F3E8` | 主背景、预览纸张 |
| Paper deep / `--paper-deep` | `#EFE4D1` | 分区、输入背景 |
| Ink / `--ink` | `#183A31` | 主文、主按钮、Quiet Night |
| Ink muted / `--muted` | `#64756C` | 辅助文、图标 |
| Clay / `--clay` | `#B85639` | 强调、进度、关键数字 |
| Sage / `--sage` | `#D8DFCB` | 照片占位、低强调卡片 |
| Line / `--line` | `#DED4C1` | 分隔线、描边 |
| White / `--white` | `#FFFCF6` | 浮层与卡片 |

字体：标题为 `Iowan Old Style` / `New York` 回退 serif；正文为 `SF Pro Rounded` / `-apple-system`。标题以 32pt/36pt（画板比例 1×）为基准；页面标题 24pt，正文 15pt/22pt，标签 11pt（全大写，1.4px 字距），辅助文字 12pt。

## 栅格与间距

- 原型画板：390 × 844（iPhone 15/16 逻辑点）。
- 水平安全边距：24；页面内容上边距：18；底部动作区：24。
- 4pt 基线：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40。
- 卡片圆角：18；照片及封面圆角：20；主操作圆角：16；胶囊标签：999。
- 点击区域最低：48 × 48。正文对比度按 WCAG AA 目标配置。

## 组件

| 组件 | 规格 |
|---|---|
| Primary CTA | Ink 实底、白字 15pt semibold、56 高、右侧箭头；不可用为 35% Ink。 |
| Secondary CTA | 无填充、Clay 文本，48 高；适于恢复购买、返回等非破坏动作。 |
| Input | Paper-deep 底、1px Line、52 高；标签在上，输入字 Ink。 |
| Segment | 2–3 项胶囊容器，选中 Ink/白字，未选中透明。 |
| Card | White 78% 不透明、1px Line、18 圆角、16 内边距。 |
| Photo tile | Sage 或带轻纹理的真实照片容器；识别状态使用左上状态点，不能只依赖颜色。 |
| Progress | Clay 圆环与可读百分比；文本明确“仅在此设备处理”。 |
| Bottom sheet | White、24 顶部圆角；错误态必须保留当前进度与“稍后重试”。 |

## 画面与素材策略

原型使用低饱和的狗/猫照片占位（CSS 剪影或虚化色块），正式制作必须以用户授权照片渲染。欢迎页可使用一张真实但不煽情的日常宠物摄影；相册页中的所有“照片”均应替换为本地 `PHAsset` 缩略图。不得使用 AI 生成照片来暗示用户的真实宠物记忆。

## 12 屏覆盖

## 未定假设（需评审冻结）

1. 目标设备基准为 390×844；小屏 iPhone SE 的纵向滚动与动态字体布局待工程验证。
2. 目前以 `Milo`、狗、2017–2024 演示；最终需要确认美国英语的默认语气和本地化策略。
3. 图中宠物为非产品资产占位，不纳入发布包；等待经过授权的品牌摄影或用户本地照片。
4. `Warm Paper` 为默认模板，`Quiet Night` 与 `Field Notes` 的最终 PDF 印刷样张、墨量和无障碍对比度尚未验证。
5. 未设计品牌标志；v1 以文字标识 `TAILOR` 启动。
6. 系统 Photo Picker、StoreKit 支付表、Share Sheet 使用原生系统样式，不在设计稿中伪造。

Click through the core E01–E09 states. The canvas is intentionally a page editor: select a photograph, move it, open Crop, switch a template, run Book Check, then enter reading preview.

  • Data contract: page elements use normalized frames; this UI never stores screen pixels.
  • Preview ≡ export: reading view removes editing chrome only; it does not build a second layout.
  • Privacy: examples are local placeholders, never generated pet memories.

# Tailor v1 详细设计交接包

## 1. 项目定位

Tailor 是美国市场、iPhone 优先的离世宠物电子相册。用户从已授权相册中找回真实照片，经确认和编辑后导出本地 PDF 纪念册。设计应传达安静、可信、私密、克制的纪念感；不使用彩虹桥、翅膀、拟人对话、复活或过度悲伤的视觉符号。

## 2. 已确认的产品范围

- 平台：iPhone，iOS 17+。
- 主流程：欢迎 → 隐私/权限 → 建档 → 参考照 → 本地扫描 → 照片确认 → 时间线 → 章节编辑 → 相册预览 → 一次性购买 → PDF 导出 → 我的档案。
- 核心承诺：照片在设备端处理；不上传完整相册；低置信度照片不自动入册；用户可删除所有本地档案数据。
- 购买：单一非消耗型解锁，`$19.99`；无订阅、无账号。
- 视觉基调：暖白纸张、深墨绿、陶土橙，真实照片优先。

## 4. 设计师交付物

### 4.1 详细页面设计

完成 12 个主页面的 iPhone 设计稿，覆盖 PRD 中每页的完整状态：

1. 欢迎与信任建立
2. 隐私说明、完整授权、受限授权、拒绝授权
3. 宠物档案创建与表单校验
4. 参考照选择、未满 3 张、已满足条件
5. 扫描中、暂停、可恢复、失败
6. 高确定、待确认、已排除、零匹配
7. 时间线、空章节、章节操作
8. 章节编辑、换封面、照片排序/删除
9. 三种模板与免费水印样章
10. 购买、购买中、取消/失败、恢复购买
11. PDF 生成、生成失败、完成和系统分享
12. 多档案、照片访问管理、删除二次确认

### 4.2 设计系统

- 色板：语义色、文字层级、分隔线、状态色和照片覆盖层。
- 排版：动态字体、中文/英文混排、长宠物名和长章节标题的截断/换行规则。
- 布局：4pt 或 8pt 间距体系、安全区、底部主操作区、单手操作触达区。
- 组件：主/次/危险按钮、分段控制器、输入框、照片格、章节卡、置信度标签、进度环、空状态、错误卡、底部 sheet。
- 动效说明：扫描进度、照片确认切换、模板切换和导出完成；只定义必要动效，不做煽情动画。
- 无障碍：动态字体最大级别、对比度、触控区域、VoiceOver 标签建议。

### 4.3 资源规范

- 真实宠物照片遵循自然光、暖纸质感、低饱和、无文字、无水印。
- 为每个需要位图的区域提供：资源名、尺寸、裁切比例、用途、生成提示词或摄影说明。
- 图标优先使用 SF Symbols；仅在品牌或叙事不可替代时新增自定义位图。
- 不把 AI 生成的宠物照片描述为用户真实宠物，所有产品解释要避免误导。

## 5. 必须冻结的设计决策

1. 品牌标志与 App Icon 方向。
2. 三个相册模板的完整页面语言，而不只是封面色差。
3. 系统照片授权受限模式的文案与回退入口。
4. 扫描过程的耗时提示、暂停、后台恢复反馈。
5. 低置信度照片的确认效率与误触保护。
6. `$19.99` 购买页法律/恢复购买文案。
7. 删除档案的二次确认、影响范围与不可逆提示。

## 6. 验收标准

- 全部页面和异常态均可映射到 PRD，且存在清晰的前进/返回/退出路径。
- 页面在 390pt 宽 iPhone 基线以及动态字体放大后不截断关键内容。
- 关键隐私承诺在欢迎、权限、扫描、导出四处一致。
- 低置信度照片绝不呈现为已被系统自动收录。
- 图片、标题和章节文案均不虚构宠物经历或情感。
- 设计交付包含 Figma/Relay 源文件、可导出资源、组件说明和开发标注。

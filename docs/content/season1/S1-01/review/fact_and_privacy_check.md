# S1-01 事实与隐私检查

## 事实门禁

| 表述 | 当前证据 | 判定 |
|---|---|---|
| App 正常流程不上传原图 | v2 PRD、PhotoKit实现与隐私政策 | 可用，避免扩大到绝对安全承诺 |
| 用户确认哪些照片进入纪念册 | Photo Review与统一eligibility规则 | 可用 |
| 支持时间线、模板、页面编辑、Book Check、PDF | PRD与当前路由/实现 | 可用 |
| 支持单页分享 | 当前分享功能与原型 | 可用 |
| 159项单元测试通过 | 当前一次完整测试结果 | 可用，必须同时说明UI/真机/商店门禁不由此自动通过 |
| 模板与设计一致 | Warm Paper source/render contract通过 | 只能说默认模板契约对齐；不能说所有模板真机像素级一致 |
| 支持纪念影片 | 只有未进入UI的本地轮播导出器 | 不可用作当前产品功能 |
| 已正式发布 | 尚无App Store正式发布证据 | 不可用 |
| 已完成美国用户验证 | 无完整研究记录 | 不可用 |
| AI独立做完整款App | 人持续给出目标、审批和验收 | 不可用 |

## 隐私门禁

- [ ] 宠物照片具有公开使用权，或替换为明确可公开/生成素材。
- [ ] 所有对话截图隐藏邮箱、Apple ID、路径中的用户名和临时链接。
- [ ] Reddit截图隐藏不必要的用户名、头像和个人信息。
- [ ] 真机截图不包含通知、联系人、位置、真实相册和支付账号。
- [ ] 不公开开发证书、Bundle配置、商品后台和密钥。
- [ ] 视频旁白和字幕不出现治疗、治愈或走出悲伤承诺。

## 主理人必须确认

- [ ] 第一人称产品动机准确。
- [ ] 愿意公开“第一版视频像PPT”和手机漂移问题。
- [ ] 愿意公开“Reddit反馈低”和“尚未完成真实用户验证”。
- [ ] 确认采用不出镜、中文旁白的第一版视频方案。

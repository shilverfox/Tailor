# 《APP 开发小白，如何用 AI 从零到一上线一款 iOS 应用》第一季

## 系列定位

面向没有完整 App 开发经验的人，以 Tailor 的真实开发与发布过程为案例，讲清楚如何借助 AI 完成产品规划、原型设计、iOS 开发、测试验收、App Store 上架和冷启动。

Tailor 是贯穿全季的案例和证据，**可复用的 AI App 开发方法才是主角**。读者不需要先成为专业产品经理、设计师或 iOS 工程师，但需要学会描述需求、组织资料、指挥 AI、验收结果并做关键决策。

系列不使用“十分钟全自动做 App”的叙事。所有对功能、测试、用户和结果的描述都必须能回到真实项目证据；没有完成或没有验证的部分明确标注。

## 每篇固定教学结构

1. 这一阶段要解决什么问题。
2. 应该向 AI 提供哪些输入、如何下达任务。
3. AI 交付后如何验收、如何识别“看起来完成”。
4. Tailor 的真实结果、返工和证据。
5. 读者可直接复用的提示词、模板或检查表。

## 状态定义

- `资料整理`：核心来源已定位，仍有授权或脱敏项。
- `制作中`：正文、视频或视觉资产正在生产。
- `待审核`：已形成完整发布包，等待主理人确认。
- `已完成`：审核修改完成，可随时发布。
- `已发布`：已经发布且进入数据回填。

# Tailor App Preview — Creative Director Cut v2

## Core problem with v1

The first cut feels like a slide deck because it treats every feature as a separate caption card. That must be rejected.

This video should not explain Tailor like a product tour. It should make the viewer feel: “I know exactly when I would use this.”

## Creative direction

Make it feel like a quiet private ritual after losing a pet:

1. A name appears.
2. A few ordinary photos become meaningful.
3. The app organizes them into a memory book.
4. The user edits one page.
5. The user shares one remembrance page.
6. The user exports a print-ready PDF.

The emotional arc is more important than showing every screen.

## Non-negotiable rules

- Do not make full-screen text slides.
- Do not hold a static app screen for more than 1.2 seconds unless there is visible motion.
- Do not use generic SaaS/product-demo music.
- Do not use loud transitions, bouncy animations, confetti, or “AI magic” clichés.
- Do not show the iOS share sheet if contacts or private data appear.
- Do not over-claim grief healing, therapy, recovery, or emotional outcomes.
- Do not say “AI creates memories.” Say the app helps build a private memory book from photos the user approves.

## Visual language

- Use a warm off-white background.
- Place the iPhone screen inside a subtle device frame or soft shadow.
- Use slow push-ins, gentle pans, and masked zooms into important UI areas.
- Use photo-to-page transitions: selected photos slide into a page layout, then become part of the book.
- Use page-turn or paper-stack metaphors sparingly.
- Captions should be small, elegant, and integrated into the frame, not separate title cards.
- Prefer lower-third captions or floating annotations near the UI action.

## Recommended 30-second structure

### 0.0–2.5s — Emotional hook

Visual: warm blank surface, then iPhone appears. The pet name field is visible or implied.

Caption:

> For the pet you loved.

Motion: slow push-in. No big title card.

### 2.5–5.5s — Personal start

Visual: pet profile/name screen. Focus on typing or completed name.

Caption:

> Start with their name.

Motion: crop into the name area, then match-cut into photos.

### 5.5–9.0s — Real photos

Visual: reference photos / photo selection.

Caption:

> Choose a few real photos.

Motion: three selected photos subtly lift forward, then flow into the next screen.

### 9.0–12.0s — Privacy trust moment

Visual: privacy or on-device copy, then scan/progress.

Caption:

> Nothing is uploaded.

Motion: keep this quiet and clear. This is a trust beat, not a technical beat.

### 12.0–16.0s — Book appears

Visual: generated draft / style / preview.

Caption:

> A memory book takes shape.

Motion: page thumbnails slide into position; gentle page-turn transition.

### 16.0–20.0s — Style choice

Visual: style screen.

Caption:

> Choose a style that feels right.

Motion: quick but soft comparison between styles. No hard cuts.

### 20.0–23.0s — Editability

Visual: editor page.

Caption:

> Edit every page.

Motion: zoom into editable text/image area; show one concrete adjustment if available.

### 23.0–26.0s — Sharing

Visual: final preview with Share page entry; avoid actual share sheet.

Caption:

> Share one remembrance page.

Motion: focus ring / subtle highlight around Share page. Then page image lifts out of the phone.

### 26.0–29.0s — Export

Visual: PDF ready screen.

Caption:

> Export a print-ready PDF.

Motion: the PDF page becomes a clean paper/book object beside the phone.

### 29.0–30.0s — End card

Visual: app name on warm background with tiny phone/book silhouette.

Caption:

> Tailor · Private Pet Memory Books

Motion: static end card is allowed only for the final second.

## Music / sound

Use soft piano, warm ambient, or acoustic texture. Keep it restrained. No corporate ukulele, no upbeat startup music.

If voiceover is used, it should be one calm sentence, not a narrated feature list:

> “Turn the photos you choose into a private memory book for the pet you loved.”

Subtitles are enough; voiceover is optional.

## Acceptance criteria

The new cut is acceptable only if:

- It does not feel like a slide deck.
- The viewer understands the product without reading every word.
- The pet loss / memory book use case is clear by 5 seconds.
- Privacy is clear by 12 seconds.
- Share and PDF export are both visible.
- There is a coherent emotional arc from name → photos → book → share/export.
- Captions support the visuals; captions do not carry the whole video.

# Tailor 本地宠物识别校准报告模板

状态：待真实设备、经用户同意的标注相册验收。本文不是模型准确率结论。

## 运行条件

- App / iOS / 设备型号：
- 宠物类型与参考图数量：
- 相册总图数、人工标注目标宠物图数：
- 识别策略版本与阈值：
- 是否仅限本机、是否有任何上传：必须为“仅本机、无上传”。

## 结果

| 指标 | 数值 | 说明 |
| --- | --- | --- |
| Candidate precision |  | 进入 selected 或 needs review 的候选中，真实目标宠物占比。 |
| Candidate recall |  | 已标注目标宠物中，进入候选的占比。 |
| High-confidence count |  | 默认 selected 的数量。 |
| High-confidence false-positive rate |  | 默认 selected 中被人工标注为非目标宠物的比例。 |
| Needs-review recall |  | 未自动选中但仍保留给人工确认的真实宠物数量。 |
| Burst/reimport groups |  | 本地视觉重复分组数；不得删除既有用户决定。 |

## 人工复核切片

- 同品种但不同宠物：
- 非目标动物（猴子、小熊猫等）：
- 人像、玩偶、宠物不在画面：
- 幼年/老年、不同姿态、逆光/低光：
- 连拍与重复导入：

## 放行标准

1. 高置信假阳性必须低于产品批准阈值，且每个高置信结果至少有两张参考图一致支持。
2. 低置信目标宠物应进入 Needs Review，不得因提高高置信门槛而静默丢弃。
3. 所有样本、特征、确认反馈只留在设备本地；报告仅记录聚合指标。
4. 未达到最小人工标注量时，禁止修改正式阈值或宣称已校准。

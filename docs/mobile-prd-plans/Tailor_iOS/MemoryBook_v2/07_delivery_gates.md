# 阶段门禁

## Gate A：允许进入实现

- 产品范围明确：自动生成不替代自由编辑器。
- 编辑器入口、退出和关键状态有设计来源。
- Document/Page/Element schema 已评审。
- 黄金 fixture 已落库。

## Gate B：共享渲染通过

- Warm Paper fixture 可同时渲染 SwiftUI 与 PDF。
- 图片框、裁切、旋转、层级、文字和分页一致；核心几何误差 ≤ 1 pt。
- A4/Letter 均通过；选择框和辅助线不进入 PDF。

## Gate C：编辑器完整

- 图片、文字、页面、层级、锁定、Undo/Redo、保存恢复全部通过。
- 只有选中对象响应变换手势。
- 打开文字属性面板不默认弹出键盘。
- 进程重启不丢草稿、不重新排版。

## Gate D：自动生成与模板通过

- 自动初稿质量内部盲评 ≥ 70% 可直接进入微调。
- 五模板灰度识别准确率 ≥ 80%。
- 锁定页面在模板重排后零变化。
- 敏感、排除、neverUse、隐藏时期照片零泄漏。

## Gate E：可发布

- Book Check 阻断项均可定位和修复。
- 飞行模式完成编辑、预览与 PDF 导出。
- 112 张黄金 fixture 无崩溃、无不可恢复卡死、无主线程长时间阻塞。
- 产品、设计、研发、测试各自提交验收记录，不以“编译通过”代替功能和视觉验收。

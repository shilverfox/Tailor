# Tailor Memory Book v2｜实施起点

> 状态：产品与原型已冻结为 `Tailor-v2.2-docfreeze-2026-07-21`；独立设计与测试审计均为 PASS（文档 P0=0、P1=0）。实现与发布门禁仍独立管理，不得直接删除或替换现有自由编辑器能力。

## 一句话目标

把“自动生成一本有叙事节奏的纪念相册”与“用户可自由调整图片和文字的页面编辑器”合并成同一个产品，并保证页面级预览与 PDF 一比一。

## 所有角色先遵守的共同基线

1. 自动生成是起点，不是最终结果；用户始终可进入完整页面编辑器。
2. 模板切换不得覆盖已手工编辑并锁定的页面。
3. `MemoryBookDocument → MemoryBookPage → MemoryBookElement` 是预览、编辑和 PDF 的唯一数据源。
4. SwiftUI 预览与 PDF 禁止各自维护一套布局算法。
5. 不编造宠物经历、情绪、生日、疾病或“最后一次”等叙事；日期来自 PhotoKit，文字来自用户。
6. 本阶段只覆盖 iPhone / iOS 17+；Android、Harmony 不在本项目范围。

## 不允许的开工方式

- 不先做“AI 自动排版”，再补文档模型。
- 不把新原型当成对旧编辑器的替换。
- 不以截图作为 PDF 的长期生成方案。
- 不让五套模板只替换背景色和字体颜色。
- 不在没有黄金 fixture 的情况下靠人工目测宣称“一比一”。

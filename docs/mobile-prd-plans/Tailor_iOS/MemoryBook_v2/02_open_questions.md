# 待确认问题

## P0 阻断项

当前没有阻止“共享模型、Warm Paper 黄金样例、编辑器衔接原型”开工的 P0 问题。

## 已关闭的 P1 决策

| ID | 决策 | 冻结结论 | 影响 |
| --- | --- | --- | --- |
| P1-01 | 用户字体范围 | 仅开放 8 个稳定字体 token：System、Rounded、System Serif、Iowan Old Style、Baskerville、Avenir Next、American Typewriter、Noteworthy；不导入任意字体文件 | PDF 字体一致性、包体与授权 |
| P1-02 | 图片元素边界 | 元素 frame 不得超出页面；旋转后的视觉内容可进入出血区并由页面裁切，不能出现透明空白 | 手势与导出裁切 |
| P1-03 | 结构页删除 | 封面、目录、结尾不可删除；可隐藏模板允许隐藏的可选内容，并解释原因 | 页面管理器规则 |
| P1-04 | 自动锁定条件 | 移动、缩放、旋转、裁切、层级、文字内容或样式变化后锁定该页 | 模板重排保护 |
| P1-05 | Book Check 忽略 | 建议可忽略，阻断项不可忽略 | 导出流程 |
| P1-06 | 自动生成等待 | 超过 2 秒显示真实进度，支持取消和稍后继续 | 体验和性能测试 |

## P2：未来版本候选，不进入 v2

- 是否在后续版本增加用户保存自定义模板。
- 是否支持跨页元素和书脊安全区。
- 是否支持 300 DPI 实体印刷专用出血规格。
- 是否支持视频相册；仍在 v1 范围外。

## 1. 黄金 fixture

建立 4 套固定文档：

1. 12 张横竖混合照片、3 章、含 1 组近重复。
2. 112 张照片、4 章、含多人/多宠物、低清和极端宽高比。
3. 仅 3 张照片的最小成册场景。
4. 含缺失 PhotoKit asset、敏感排除、隐藏时期和长文本的异常场景。

每套 fixture 在 5 模板 × A4/Letter 下保存基准 PNG 和 PDF。

## 2. P0 用例

| ID | 场景 | 操作 | 预期 |
| --- | --- | --- | --- |
| T-01 | 自动初稿 | 使用 112 张 fixture 生成 | 无敏感/排除图；不复制照片填页；章节按时间稳定 |
| T-02 | 进入自由编辑 | Preview 点击 Customize，再选中图片 | 出现图片上下文工具，全部已有编辑能力可用 |
| T-03 | 仅选中元素响应 | 选中 A 后在 B 上做缩放/旋转 | B 先被选中但当次不编辑；A 不变化 |
| T-04 | 图片等比 | Fit 显示横竖图并放大缩小 | 不拉伸；裁切只发生在 Fill/Crop 模式 |
| T-05 | 图片旋转 | 双指旋转 | 图片元素框与内容共同绕中心旋转 |
| T-06 | 文字面板 | 选中文字后打开属性 | 不自动弹键盘；字号连续、颜色和字体可调整 |
| T-07 | 文字旋转 | 拖动右下旋转柄 | 围绕中心连续旋转，导出一致 |
| T-08 | 层级 | 两元素重叠并置顶/置底 | SwiftUI 与 PDF 层级一致 |
| T-09 | 锁定保护 | 修改第 4 页，再用 Cinema 重排 | 第 4 页不变；未锁页按 Cinema 重排 |
| T-10 | Undo/Redo | 自动重排、图片移动、文字修改 | 每次操作按事务正确撤销/恢复 |
| T-11 | 重启恢复 | 编辑后杀进程重开 | 恢复最后成功保存状态，不重新自动排版 |
| T-12 | 双渲染一致 | 同 fixture 预览并导出 | frame/crop/rotation/zIndex/text/page count 一致 |
| T-13 | 内容安全 | 混入 neverUse/敏感/隐藏图 | 生成、编辑候选、预览、PDF 均不可见 |
| T-14 | 缺失资产 | 删除系统相册中的已用照片 | 占位并 Book Check 阻断；可替换，不崩溃 |
| T-15 | PDF 离线 | 飞行模式导出 A4/Letter | 成功，文件可分享，草稿保留 |

## 3. 模板差异验收

- 将所有页面转为灰度后，评审者仍能正确识别至少 4/5 模板。
- 任两模板在页面配方分布、图片处理、字体或章节开场中至少有 3 个结构差异。
- 模板应用前必须给出影响页数与锁定页数。

## 4. 自动生成质量验收

- 近重复组默认最多选 1 张，用户显式保留除外。
- Hero 页主体不被安全区切断；Book Check 捕获无法安全裁切的照片。
- 同一配方不连续出现超过 2 页。
- 章节至少覆盖真实存在的时间段；素材不足不生成虚假章节。
- 20 份内部黄金样例中，首稿无需结构重做即可进入文字微调的比例目标 ≥ 70%。

## 5. 性能与稳定性

- 112 张 fixture 初稿规划可取消，不阻塞主线程。
- 翻页、选中和拖动无明显掉帧；大图按需解码。
- 后台、锁屏、内存警告、PhotoKit 权限变化和进程重启均不丢草稿。
- PDF 失败不留下可分享的半成品；重试继续使用同一文档 revision。

# 需要产品/设计补充的输入

以下不阻塞当前本地功能开发，但阻塞发布结论：

1. 敏感素材本地策略：允许的视觉线索、阈值、误判后的默认去向、禁止推断边界。
2. Figma/Relay：12 页及敏感、隐藏、扫描/购买/PDF 失败态的节点或截图；请标注 iPhone 设计尺寸与组件状态。
3. PDF 性能验收：目标相册规模、最大选片数、最大页数、生成时间和内存预算。
4. App Store Connect：商品 ID、地区价、隐私标签、Sandbox 测试账号/StoreKit 配置。
5. 产品口径：时期隐藏是否仅按年份；`excludedReason` 最终枚举和用户展示文案。

可直接回复：`敏感策略：…；时期隐藏：…；PDF 预算：…；设计稿：路径/链接；商品配置：…`。

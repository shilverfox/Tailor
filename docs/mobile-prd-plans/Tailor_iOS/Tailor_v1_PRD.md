# Tailor v1 产品需求文档

## 1. 定义与范围

Tailor 面向近 12 个月失去猫或狗、仍保留相册照片的美国 iPhone 用户。它只使用用户授权范围内的真实照片，在端侧找回、整理并输出可编辑的纪念 PDF；不生成虚构的宠物记忆。

Tailor 是一项由用户**显式启动**的私密整理工具，不是心理治疗、哀伤干预或“自动唤起回忆”的服务。它不得根据照片内容、离开年份或使用间隔主动提醒用户宠物离世，也不得推送、轮播或自动打开旧照片。

v1 为 iOS 17+、iPhone-only。交付闭环：相册授权 → 建档与参考照 → 本地扫描 → 人工确认 → 时间线编辑 → 样章预览 → 一次性解锁 → 本地 PDF 导出。范围外：视频、云端 AI、账户、同步、外部相册、分享链接、订阅、实体印刷和人工编辑。

## 2. 成功标准

| 指标 | v1 验收口径 |
| --- | --- |
| 完成闭环 | 新用户可在同一设备完成建档、确认、编辑、导出 |
| 隐私 | 原图不上传、不复制、不修改；用户可删除所有 Tailor 本地数据 |
| 可控性 | 低置信度照片不自动入册，照片/章节/标题均可编辑或删除 |
| 情绪安全 | 用户可暂停并搁置档案；敏感照片不会自动进入时间线、预览或 PDF，且可标记为永不使用 |
| 预览可信度 | 未购买用户可查看由其真实已选照片生成的 6–8 页带水印样章，足以验证选片与排版 |
| 韧性 | 授权受限、扫描中断、购买失败、PDF 失败都保留编辑进度 |
| 离线 | 扫描、编辑和 PDF 生成在飞行模式可用；内购除外 |

## 3. 用户流与状态机

`welcome → privacy → profile → references → scanning ↔ paused → confirmation → timeline → chapterEditor → preview → purchase → export → archive`

`permissionDenied` 可进入手动选择；`scanFailed`、`purchaseFailed`、`exportFailed` 均回到可重试状态，绝不清空已确认素材。档案生命周期为 `draft / scanning / ready / exported / deleted`。

任何 `draft`、`scanning`、`ready` 档案都可被用户“稍后继续”：退出 App、切后台、锁屏或手动暂停后保留本地状态；下次只能在用户主动打开 Tailor 并点击对应档案后恢复。v1 不发送本地通知、推送、周年提醒、每日回忆或照片轮播。

## 4. 页面规格

| ID | 页面 | 必要元素 | 主要动作/状态 |
| --- | --- | --- | --- |
| 01 | 欢迎 | 暖白底、真实宠物视觉、创建按钮、隐私入口 | 首次进入，不展示价格 |
| 02 | 隐私/权限 | 本机处理、不会上传、只用确认照片三项说明 | 完整/受限/拒绝；拒绝可手动选择 |
| 03 | 创建档案 | 猫狗切换、名称、到家年份可选、离开年份 | 名称和类型必填；年份用于边界 |
| 04 | 参考照 | 3–5 个照片槽位与选取提示 | 少于 3 张不可开始扫描 |
| 05 | 扫描 | 深绿背景、进度、数量、缩略图、暂停 | 仅由用户点击开始；前后台保存进度并可恢复，不触发任何通知 |
| 06 | 照片确认 | 高确定/待确认/已排除/敏感待确认分组、年份筛选、查看原图 | 是它/不是它、批量排除、标记敏感、标记“永不使用”；敏感与永不使用照片不进入后续页面 |
| 07 | 生命时间线 | 年份轴、3–6 章节卡片、代表图、隐藏状态 | 删除、合并、排序、隐藏章节；隐藏章节不进入预览与 PDF |
| 08 | 章节编辑 | 标题、用户自写说明、真实照片九宫格、封面选择 | 仅生成中性默认标题；用户可覆盖、增删照片、设置封面和排序；不生成臆测性文案 |
| 09 | 风格/预览 | Warm Paper、Quiet Night、Field Notes，真实分页样章 | 未购买展示封面、目录、至少 2 个章节和结尾在内的 6–8 页带水印样章；样章必须使用用户已选照片 |
| 10 | 购买 | 交付清单、$19.99、恢复购买 | 取消或失败保留状态 |
| 11 | 生成/完成 | 渲染进度、封面、保存/分享/返回 | 写入沙盒并使用系统分享 |
| 12 | 档案/设置 | 档案卡、重扫、访问管理、删除数据 | 删除二次确认，只删本地数据 |

## 5. 业务规则与文案边界

- 仅支持狗和猫；其他物种显示“目前仅支持狗和猫”。
- 无充分证据时以“2018–2020”“那些一起度过的日子”等中性标题替代“第一次回家”等推断性叙事。
- 禁止出现“复活”“天堂来信”“宠物对话”等拟真内容、彩虹桥/翅膀等过度煽情视觉。
- 默认相册结构：封面 → 给它的一句话 → 时间线目录 → 3–6 章节 → 结尾页。
- 不做每日回忆、周年提醒、离世后自动通知、后台自动扫描、系统级照片轮播；未来若提供任何提醒，必须为独立且默认关闭的显式 opt-in 功能，不属于 v1。
- 不将“宠物离世”作为情绪营销、付费催促或文案触发条件；购买页只能陈述交付内容、价格和隐私承诺。
- 不做治疗、诊断、心理干预或“帮助走出悲伤”承诺。

### 5.1 敏感素材与“准备好再继续”

1. **默认保护。** 扫描结果中，系统根据用户确认和本地可见线索标记为医院、病重、临终、遗体或明显低质量的素材，只能进入“敏感待确认”，不得默认选入。无法可靠判断时，必须按普通低置信候选处理，不能声称识别了病情或死亡原因。
2. **用户优先。** 用户可将任一候选标记为“敏感，稍后决定”或“永不用于此档案”。“永不使用”立即从所有章节、封面、预览和未来 PDF 渲染中移除；它不修改、隐藏或删除系统照片。
3. **时期隐藏。** 用户可按年份或日期范围隐藏一个时期。该时期在时间线显示为已隐藏，但不展示代表图，也不会进入预览/PDF，直到用户显式恢复。
4. **安全退出。** 确认、时间线、编辑和预览页均提供返回档案的路径；用户可在任一步退出。退出不显示“你还没有完成”之类的催促文案，也不安排后续提醒。

### 5.2 选片与章节生成规则

1. 选片排序优先保证跨年份覆盖、成长变化、日常场景和人与宠物互动；不能只按分辨率、曝光或清晰度排序。
2. 相同时间段的连拍、重复图和近似图默认降权，但始终保留给用户人工加入的入口。
3. 只有 `selected` 状态且未被标记敏感、未在隐藏时期、未标记永不使用的照片可成为章节素材、封面或 PDF 图片。
4. 章节由实际日期跨度与用户确认素材建立。证据不足时生成中性章节标题；任何“第一次”“最爱”“最后”等叙事性标题均须由用户亲自填写或确认。
5. 章节文字只可使用照片日期、用户允许使用的地点信息与用户输入的回忆。不得推测性格、病情、死亡原因、家庭关系或宠物的主观感受。

### 5.3 免费预览与购买边界

1. 免费预览固定生成 6–8 页：封面、时间线目录、至少两个不同时段的章节页、选片页和结尾页。若素材不足，展示说明页而非填充虚构内容。
2. 所有免费预览页必须有清晰水印；购买后以同一套用户确认的内容重新生成无水印完整 PDF。
3. 未购买用户可以继续修改照片、章节、封面、样式与页尺寸；购买失败、取消或恢复购买失败均不丢失编辑状态。

## 6. 数据、权限与技术约束

使用 PhotoKit 读取 `PHAsset.localIdentifier`、创建日期与缩略图；不保存原始照片副本。以 SwiftData 保存 `PetProfile`、`PhotoDecision`、`Chapter`、`AlbumStyle` 与购买状态。`ArchivePhoto` 必须额外保存本档案内的 `sensitivityState`（normal / needsSensitiveReview / hiddenUntilUserDecides / neverUse）、`excludedReason` 与本地日期范围归属；`Chapter` 必须保存 `note`、`coverPhotoID` 或等价的有序照片列表，以及隐藏状态。识别层定义为可替换端侧 Vision/Core ML 协议，需在 ML 技术评审后落地参考照特征与相似度阈值。PDF 使用本地渲染，支持 A4/US Letter。使用 StoreKit 2 管理非消耗型 `tailor.life_archive.unlock`。

本地档案不得注册通知、上传情绪标签或生成供广告/推荐使用的宠物离世、敏感阶段、用户文字等衍生数据。仅允许记录不含照片、名字、元数据和章节内容的本地匿名漏斗事件。

## 7. 发布前必须关闭的 P0

1. 同一宠物端侧识别模型、阈值、耗时/耗电预算、幼年到老年差异策略。
2. App Store Connect 商品、地区定价、审核与隐私标签。
3. Figma/Relay 覆盖 12 页及权限、扫描、内购、导出失败态的正式视觉规格。
4. 敏感素材的本地分类策略、误判降级策略和“永不使用”数据迁移/删除语义；不能以病情或死亡原因推断作为产品承诺。
5. 6–8 页真实水印预览与无水印完整 PDF 的内容一致性、页面容量和大相册性能预算。
6. 无通知/无自动回忆回归验收：首次启动、回到前台、系统照片库变化、离开年份到达周年等事件均不得触发提醒或自动展示照片。

## 执行顺序

1. DES-11/DES-12、IOS-11、QA-11 立即并行。
2. IOS-12 与 IOS-13 在数据迁移完成后并行；QA 持续补覆盖。
3. IOS-14 以设计页面结构冻结为输入；QA-12 进行真机 PDF/视觉验证。
4. P0：ML 策略、正式视觉规格、PDF 性能、内购配置和无自动回忆回归关闭后，才可宣称 v1 发布就绪。
5. PM-13、DES-13、IOS-16、QA-13 为当前阻断项：确认页可发现性与创建前决策闭环未通过前，不得宣称照片确认流程可用或可发布。

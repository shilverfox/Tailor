# 日期叙事、动态版式、生日页与视频导出：最小验收边界

## 当前可验收（v1）

| 能力 | 最小 fixture / 断言 | 当前状态 |
| --- | --- | --- |
| 日期叙事 | 两个可见章节（2018、2023）按 `sortOrder` 输出；页标题仅来自用户标题，不能自动出现 `first` / `favorite` / `last` | 已由 `MemoryBookBuilder` 单测覆盖 |
| 动态版式 | 同一组页面模型在 Warm Paper、Quiet Night、Field Notes 与 A4/Letter 下保留相同页顺序、标题、照片 ID；仅样式/纸张尺寸变化 | 页面模型单测覆盖；视觉尺寸待逐模板截图验收 |
| 预览/PDF 一致性 | 两者都从同一个 `MemoryBookDocument.pages` 生成；隐藏章节、`neverUse`、非 selected 照片不进入任何页 | 页面模型与 PDF 边界已有覆盖 |
| 免费预览 | 未购买页有水印、已购无水印；当前两可见章节 fixture 产生 8 页 | UI 测试覆盖 CTA，逐页视觉仍需 approved 基线 |

## 不能标记为已实现

| 需求 | 所缺模型/接口 | 最小可验收 fixture |
| --- | --- | --- |
| 自动日期叙事 | 日期聚类与受控文案策略（仅日期/用户输入）；当前只消费既有章节 | 跨年、同年、无日期、隐藏日期范围；输出中性 `2018–2020`，不产生推断叙事 |
| 动态版式 | `MemoryBookPage` 缺少 layout variant、image aspect/slot、overflow 规则 | 1/2/6/9 张、横竖混合、超长标题和 note；A4/Letter 三模板均不裁切 CTA/正文 |
| 生日页 | `MemoryBookPageKind.birthday`、生日来源/用户确认字段与关闭入口 | 明确生日、仅年份、未知生日、用户关闭；未知时绝不猜测具体日期 |
| 视频导出 | 视频页面模型、端侧帧/音频处理、渲染状态、存储/分享契约 | 0/1/多照片、取消、后台恢复、磁盘不足、无照片权限；必须默认不自动生成或播放 |

生日页和视频均不属于当前 `Tailor_v1_PRD.md` 范围，未增加 UI 伪 fixture，以免将未授权需求误报为完成。

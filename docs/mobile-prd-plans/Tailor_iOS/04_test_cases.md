# 04 测试用例（Tailor v1）

## 测试范围

覆盖 iOS 17+、iPhone-only 的端侧闭环：授权 → 建档 → 参考照 → 扫描/暂停恢复 → 照片确认 → 时间线/章节编辑 → 6–8 页水印样章 → 解锁 → 本地 PDF 导出/分享 → 档案管理。

重点验证隐私与情绪安全边界：Tailor 不注册或发送通知、不自动扫描或回忆；敏感和“永不使用”素材不进入后续成品；隐藏时期不进入预览/PDF；失败、离线、后台和锁屏不丢失编辑数据。

不在 v1 范围：视频、云端 AI、账号/同步、外部相册、NAS、私密链接、订阅、实体印刷、治疗或哀伤干预声明。

## 发布阻断（P0）

1. 任一敏感、`hiddenUntilUserDecides`、`neverUse` 或隐藏时期照片进入章节、封面、免费样章或 PDF。
2. 未购买预览不是用户真实已选照片的 6–8 页，或任一预览页缺失水印。
3. 首次启动、前后台、照片库变化、周年触发通知、自动扫描或自动展示历史照片。
4. 扫描、购买、导出失败，或后台/锁屏/重启后丢失已确认照片、章节、样式或页尺寸。
5. 飞行模式下扫描、编辑或本地 PDF 生成不可用（内购除外）。
6. 删除档案影响系统照片，或未彻底清除该档案本地数据。
7. 存在待确认照片时，用户无法在无口头指导下找到可见的选入/排除操作，或点击创建时间线后被静默带着少量已确认照片进入后续流程。

## 不可测项与待补充

| 项 | 原因 | 需要补充 |
| --- | --- | --- |
| 医院/临终/遗体等敏感识别准确率 | v1 尚无冻结的端侧分类模型、阈值和标注集 | ML 评审后的离线标注集、召回/误判目标与降级策略 |
| 同一宠物幼年到老年识别质量 | 无已验收特征模型与样本基准 | 模型版本、相似度阈值、猫狗多年龄基准集、耗时/耗电预算 |

| PDF 像素级视觉验收 | 设计稿/页模板尚需冻结 | A4/Letter 视觉基线 PDF 与截图对比阈值 |

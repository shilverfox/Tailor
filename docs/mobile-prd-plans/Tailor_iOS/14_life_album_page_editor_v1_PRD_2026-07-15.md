# Tailor 生命相册页面编辑器 v1 PRD

> 文档状态：待评审（产品 / 设计 / iOS / 测试）  
> 优先级：P0，Tailor 的核心付费能力  
> 关联基线：[Tailor v1 产品需求文档](Tailor_v1_PRD.md)、[页面编辑器与一比一导出](13_page_editor_export_architecture_2026-07-15.md)

## 1. 背景、问题与产品判断

Tailor 已能将用户确认的真实照片按时间组织为章节，但现有“预览”和 PDF 导出均偏向程序化摘要：页面留白、照片容量、模板应用与导出成品缺乏一致的编辑语义。它只能验证闭环，不能构成用户愿意付费保存、打印或交给家人的纪念成品。

生命相册的核心价值不在于“生成一个 PDF 文件”，而在于用户能够以自己的方式安排真实照片，看到一册可被信任、可被修改、与最终输出一致的相册。页面编辑器是该价值的承载层，必须在不编造宠物记忆、不上传照片的前提下，提供克制、精美、可控的版式表达。

### 1.1 用户目标

| 用户目标 | 编辑器必须提供的能力 |
| --- | --- |
| 看见宠物一生，而非一堆排序照片 | 按时间线自动成册、章节页、目录、可按页查看 |
| 保证没有不想出现的照片 | 只使用已确认且可入册的照片；页内删除不影响系统照片；敏感/隐藏/排除照片不可进入页面 |
| 让成品看起来像“我的相册” | 多套品牌模板、封面图、照片位置/裁剪、标题和回忆文字可编辑 |
| 不担心导出变样 | 编辑画布和 PDF 基于同一个页面数据模型；导出前可查看逐页预览 |
| 随时停下、以后再改 | 自动草稿保存、撤销/重做、退出后从档案继续 |

### 1.2 成功标准

1. 用户可从时间线进入相册编辑器，在不离开 App 的情况下完成自动成册、逐页修改、预览、导出。
2. 任一已保存的图片位置、尺寸、裁剪、旋转、顺序、文字与页面模板，导出的 PDF 必须与预览语义一致。
3. 用户可在不使用云端、飞行模式下完成编辑、预览和 PDF 导出。
4. 未解锁用户能以真实用户照片查看带水印样章并完成编辑；付费只解锁完整无水印导出，不限制创作。
5. 用户无需逐张手动排版即可获得可阅读的初稿；自动布局不可覆盖已手动调整的页面。

## 2. 范围与非范围

### 2.1 v1 范围（P0）

- 以 `MemoryBookDocument → MemoryBookPage → MemoryBookElement` 为唯一页面数据源。
- iPhone 纵向单页编辑画布；可前后翻页、缩略图导航、全册预览。
- 固定页面类型：封面、献词、目录、章节开场、照片页、里程碑页、结尾页。
- 5 套模板：Warm Paper、Quiet Night、Field Notes、Cinema、Film Album。
- 图片元素：替换、删除、添加、拖动、缩放、裁剪、旋转、前后层级、页面内排序。
- 文本元素：标题、副标题、日期、用户备注；可编辑既有可编辑字段。
- 版式：单图、双图、2×2/3×2 拼贴、注记页、章节开场、封面；自动排版与恢复模板。
- 自动保存、撤销/重做、放弃未保存修改、恢复已保存草稿。
- 逐页 SwiftUI 预览和同一模型驱动的本地 PDF 输出；A4/US Letter。
- 免费水印样章、解锁后无水印全册导出、再次进入档案访问最近 PDF。

### 2.2 不在 v1 范围

- 自由绘画、贴纸、音乐、视频剪辑、动画或 AR 相册。
- 用户自建任意模板、模板商店、多人协作、云同步、网页分享链接。
- 自动生成宠物第一人称、情绪判断、生日/疾病/离世原因等未经用户输入或确认的叙事。
- 复杂专业桌面排版（自由出血线、CMYK、装订、跨页手动联动、图层蒙版、富文本）。
- 对系统照片作任何删除、编辑或写回；Tailor 中的编辑只保存显示参数和资产标识。

## 3. 核心原则与内容边界

1. **真实且可控。** 相册只使用用户确认且可入册的真实 `PHAsset`；不生成或补造照片、行为、情绪、关系和事件。
2. **一份文档、两种渲染。** SwiftUI 编辑器、样章预览和 PDF 导出均消费同一 `MemoryBookDocument`，禁止维护第二套页面坐标、选片或模板规则。
3. **自动初稿，人工决定。** 自动排版给出起点；用户的手动变更优先且不可被自动刷新覆盖。
4. **克制纪念。** 不出现彩虹桥、翅膀、复活、天堂来信、宠物对话等拟真或煽情表达。
5. **安全退出。** 页面内删除、重新排版、模板变更均可撤销；离开编辑器不以未完成状态催促用户。

## 4. 信息架构与主流程

```text
生命时间线
  └─ 编辑相册 / 预览相册
      └─ 相册编辑器（页缩略图 + 单页画布）
          ├─ 页面操作：新增 / 删除照片页、复制照片页、重排页面
          ├─ 元素操作：图片 / 文本选择与编辑
          ├─ 模板与版式：全册模板、单页版式、自动排版、恢复模板
          ├─ 预览模式：逐页阅读、显示水印状态
          └─ 导出准备
              ├─ 未购买：带水印样章 → 解锁页
              └─ 已购买/调试绕过：完整预览 → 本地 PDF → 保存/分享/档案
```

### 4.1 页面状态机

`timeline → editor.loading → editor.editing ↔ editor.previewing → export.preparing → export.rendering → export.completed`

- `editor.editing`：允许修改文档，保存草稿。
- `editor.previewing`：只读、可翻页；“返回编辑”保持选择页和草稿。
- `export.preparing`：校验照片可用性、页数和付费状态；不改变草稿。
- `export.rendering`：锁定当前文档快照；渲染失败返回编辑器并保留草稿。
- `purchase.required`：未解锁点击完整导出时出现；取消后回到同一页预览。

## 5. 页面规格

### 5.1 E01 相册入口（时间线/预览页）

| 项目 | 规格 |
| --- | --- |
| 入口 | 时间线底部主按钮“Edit album”或“Preview album”；已有文档显示“Continue editing”。 |
| 信息 | 当前模板、页数、最近编辑时间、是否有未导出修改、免费/已解锁状态。 |
| 行为 | 首次进入构建自动初稿；再次进入加载保存的 `MemoryBookDocument`，不得重置已编辑元素。 |
| 空态 | 没有可入册照片时显示“Choose photos to begin”，跳转照片确认页；不创建空白付费相册。 |

### 5.2 E02 相册编辑器（主画布）

**布局（iPhone 竖屏）：**

- 顶栏：返回、页面序号（例如 `4 of 18`）、撤销、重做、更多菜单。
- 主区域：按当前目标纸张比例缩放的单页画布；画布外为中性深色工作区，页面本身明确绘制模板背景。
- 底栏：`Pages`、`Layout`、`Photo`、`Text`、`Style` 五个上下文工具入口。无元素被选中时显示页面级工具；选中元素时显示元素工具。
- 页底缩略条：显示当前页附近缩略图；支持点击跳转和长按拖动换页顺序。较小屏幕可由 `Pages` 弹出全屏页面管理器。

**选择规则：**

- 点按图片/可编辑文字选中元素，显示陶土橙描边及控制点；再次点按空白处取消选择。
- 不允许选中模板固定装饰、默认水印或系统日期页码。
- 选中元素后底栏只展示当前元素可用操作，避免把图片操作展示给文字元素。

### 5.3 E03 页面管理器

| 能力 | 规则 |
| --- | --- |
| 缩略图浏览 | 显示所有页类型、页码、章节归属、是否含编辑变更；不在缩略图加载全分辨率原图。 |
| 重排页面 | 仅允许拖动照片页和里程碑页；封面固定第 1 页，献词/目录在封面后，结尾固定最后。章节开场页须位于其所属照片页之前。 |
| 新增页 | 仅能新增“照片页”或“注记页”；系统自动分配到当前章节，用户也可选择其它未隐藏章节。 |
| 删除页 | 仅能删除非结构固定页；删除前二次确认，删除的是页面布局而非照片或章节。 |
| 复制页 | 仅照片页/注记页可复制；复制后所有元素、顺序与样式复制，但后续编辑相互独立。 |

### 5.4 E04 图片编辑面板

| 操作 | 交互与约束 |
| --- | --- |
| 添加 | 从本档案“已选照片”选择；不可浏览未确认、敏感待定、永不使用或隐藏时期照片。添加后采用当前页空槽或自动创建新照片页。 |
| 替换 | 点“Replace”进入同一照片选择器；保留元素框、旋转和层级，重置裁剪为适配新图片。 |
| 删除 | 点“Remove from page”只移除页面元素；照片仍保留在档案/章节中。若页面无内容，提示删除页面或保留为空白注记页。 |
| 拖动 | 单指拖动改变归一化 `frame` 原点；边界吸附到安全边距、中心线和相邻元素边缘，显示辅助线。不可拖至页面可视区域外。 |
| 缩放 | 双指捏合改变元素框，最小边长为页面短边的 12%，最大不超过页面安全区；保持图片填满框。 |
| 裁剪 | 点“Crop”进入裁剪模式，固定元素框、拖动图片内容和捏合图片缩放；完成/取消明确区分。图片不能露出空白。 |
| 旋转 | 默认隐藏；在“More”内按 1° 步进或控制柄拖动，范围 `-15°…15°`；长按复位。v1 不支持任意 360°。 |
| 层级 | `Bring forward` / `Send backward`；仅相同页图片/文本可调整，模板背景始终最底层。 |
| 重设 | `Reset photo` 恢复该元素的模板默认框、裁剪、旋转和层级；有二次确认且可撤销。 |

### 5.5 E05 文本编辑面板

| 文本类型 | 可编辑字段 | 限制 |
| --- | --- | --- |
| 封面 | 宠物名、副标题、年份范围 | 宠物名来自档案，可在此覆盖但不反写档案名；副标题默认中性。 |
| 章节开场 | 章节标题、年份/日期范围、用户备注 | 不提供自动臆测文案；日期仅来自照片元数据。 |
| 照片页 | 可选页标题、用户注记 | 最多 120 个拉丁字符或等长本地化字符；不支持自动“心情标签”。 |
| 献词/结尾 | 用户亲自输入的一句话 | 最多 240 个字符；默认留空或中性占位，绝不代写宠物口吻。 |

- 文本框可在模板允许的安全区域拖动和调整宽度；字号由模板提供 3 档（Small / Default / Large）。
- 字体、颜色、行距仅从模板语义 token 中选择，v1 不提供任意字体/颜色选择器，避免失去成品一致性。
- 文本溢出时显示红色提示和“Fit text”建议；导出前必须解决溢出。

### 5.6 E06 模板与版式面板

**全册模板：**

| 模板 | 视觉语义 | 不可变品牌约束 |
| --- | --- | --- |
| Warm Paper | 暖白纸张、深墨绿文字、陶土橙强调 | 低饱和、纸张感留白 |
| Quiet Night | 深墨绿夜色、暖白文字、克制边框 | 所有文字必须达到可读对比度 |
| Field Notes | 浅苔绿、卡片/注记式时间记录 | 保持真实日期与手记感 |
| Cinema | 黑白或低饱和全幅照片、少量文字 | 非煽情、无过度滤镜 |
| Film Album | 胶片边框、可见日期/注记区 | 不模拟褪色到损害照片可辨识度 |

**应用规则：**

- `Apply to entire book`：更新全册样式 token、背景、字体等级、默认装饰；不改变用户图片框、裁剪、文字内容或页顺序。
- `Apply to this page`：可将当前页面设置为全册模板的“局部覆写”，页面管理器标识“Custom style”。
- `Restore page style`：移除局部覆写，恢复全册模板；确认后可撤销。
- `Layout` 只影响当前照片页。切换单图/双图/拼贴时，保留同页可容纳的前 N 张图片；超出容量的图片自动移到同章节新照片页，并在操作前显示结果说明。

### 5.7 E07 自动排版与检查

自动排版入口位于 `Layout → Auto arrange`，需提供作用范围选择：`This page`、`This chapter`、`Entire book`。

自动排版规则：

1. 按日期排序，优先跨年份、成长变化、日常/互动覆盖；连续相似照片降权但不删除。
2. 每章节至少一页章节开场；照片按 1、2、4、6 张选择单图、双图、2×2、3×2 模板。
3. 只自动处理用户明确选定范围内的“未锁定”页面/元素。用户拖动、裁剪、替换或编辑过的元素自动标记 `isLayoutLocked = true`。
4. 自动排版前显示将影响的页数、会新增/删除的照片页、不会动的已锁定元素。确认后执行为单个可撤销事务。
5. 不能创建“第一次回家”“最后的日子”等叙事标题；只生成中性日期范围或既有章节名。

`Check book` 在导出前或用户主动点击时检查：空白照片框、文字溢出、缺失资产、低清晰度警告、重复照片、含水印状态、隐藏照片泄露。检查只建议，不擅自删除内容；缺失资产、文字溢出、无可导出照片为阻断项。

### 5.8 E08 阅读预览与导出准备

- 预览为全屏逐页阅读，不显示编辑控制柄；左右滑动/点按翻页，页码可见。
- 预览按目标 PDF 尺寸显示页面比例；缩放仅改变屏幕查看，不改变文件布局。
- 未购买：展示 6–8 页真实带水印样章，必须包含封面、目录、至少两个不同时段、至少一个照片页和结尾。用户始终可回编辑器。
- 已购买（或开发调试绕过）：展示全册无水印预览，点击 `Export PDF` 前显示页数、A4/US Letter、预计文件大小。
- 若用户已选但尚未购买，不得把编辑器限制成只读或暗示“失去回忆”；仅对无水印完整导出设付费门槛。

### 5.9 E09 导出完成与档案

- 渲染中显示页数进度、可取消（取消保留草稿）；不得在后台上传或把文件自动分享。
- 成功后显示封面缩略、生成时间、页数、`Save to Files`、`Share`、`Open in archive`。
- PDF 必须持久保存在 App 沙盒；档案页显示“Latest exported PDF”，下次进入可再次分享。重新导出不覆盖旧文件，除非用户明确选择“Replace latest”。

## 6. 页面级编辑规则

### 6.1 归一化几何与可编辑元素

所有可见对象以目标页面坐标系 `0...1` 保存，不保存 iPhone 屏幕像素。`MemoryBookElement` 至少包含：

```text
id, kind(image/text), assetID/text, normalizedFrame,
cropScale, cropOffset, rotation, zIndex,
styleOverride, isLayoutLocked, createdBy(auto/user), updatedAt
```

- 图片 `normalizedFrame` 是页面上的容器框；`cropScale/cropOffset` 是容器内图片显示参数。
- 文本框的高度可随内容扩展，但必须保持在安全区；排版引擎将最终字体度量写回可渲染布局。
- 不可编辑页面背景、模板装饰、水印、自动页码均不是 `MemoryBookElement`，由 `PageStyle` 渲染。

### 6.2 保存、撤销与重做

| 场景 | 行为 |
| --- | --- |
| 单次拖动/缩放/裁剪结束 | 结束手势后合并为一条撤销记录；自动保存延迟不超过 1 秒。 |
| 文本编辑 | 失焦或点击完成时写入一条撤销记录；输入过程不逐字符记录。 |
| 模板切换/自动排版/页面重排 | 每次操作是一个原子事务，可一次撤销。 |
| 撤销/重做 | 当前会话至少保留 50 个操作；退出后不要求保留操作栈，但已保存草稿必须保留。 |
| 返回 | 草稿已自动保存；若正在裁剪或有未完成文本输入，弹出“Keep editing / Save and leave / Discard this edit”。 |
| 崩溃/强杀 | 以最近一次已提交事务恢复；不要求恢复未结束手势中的中间位置。 |

### 6.3 照片可用性与重复规则

- 只有 `selected && normal && !neverUse && !inHiddenPeriod` 的照片可添加或导出。
- 若 `PHAsset` 被用户从系统相册删除、权限改变或无法加载，保留灰色占位和“Replace”入口，阻断导出直到处理。
- 同一资产允许在不同页面重复使用，但插入时提示“Already used on page X”；自动排版默认不重复。
- 视觉近似/连拍照片由扫描/选片层降权；编辑器只给出“Possible duplicate”提示，不自行移除用户放入页面的照片。

## 7. 一比一预览与 PDF 导出要求

### 7.1 共享渲染契约

1. `MemoryBookDocument` 是唯一业务输入；预览和 PDF 不得重新按章节选片、重新决定版式或重新排序。
2. 模板必须定义平台无关的 `PageStyle`（背景色、边距、安全区、字体 token、边框、滤镜、装饰规则）；SwiftUI 与 Core Graphics/Quartz 使用同一组 token。
3. 图片容器、裁剪、旋转、层级、文字 frame 均按归一化坐标映射到目标页面。映射仅改变物理尺寸，不改变相对关系。
4. PDF 渲染前冻结文档快照及资产加载结果；渲染期间继续编辑不会影响本次输出。
5. 预览中实际使用的图片与 PDF 必须是同一 `localIdentifier`；导出时可请求更高分辨率，但不可替换成其他照片或重新裁剪。

### 7.2 质量与容错

- A4 与 US Letter 纸张均支持；预览可切换纸张并提示比例变化，用户布局按归一化坐标保持。
- PDF 每页必须显式填充页面背景，禁止透明页在阅读器中显示黑底。
- 对打印目标，图片按可用原始尺寸请求，无法满足建议质量时显示“May print softly”警告，但由用户决定是否继续；不得伪造 DPI。
- 导出失败（磁盘不足、资产不可用、渲染异常）展示原因与重试/返回编辑，不丢失草稿，也不把失败文件显示为可分享成品。

### 7.3 一比一验收容差

同一设备、同一文档、同一模板、同一纸张规格下，导出 PDF 栅格化到预览基准尺寸后：

- 元素边界位置误差不超过页面长边的 0.5%。
- 图片裁剪焦点与预览一致，差异不超过容器短边的 1%。
- 文本换行、字号等级、对齐和可见内容一致；若系统字体替换导致不一致，导出被视为失败而非接受差异。
- 背景、模板边框、水印（仅免费样章）及页序一致；不允许空白、黑页、重复页或缺图。

## 8. 空态、异常与安全退出

| 情况 | 呈现与恢复 |
| --- | --- |
| 无可入册照片 | “Choose photos to begin”；提供回照片确认，不创建空相册。 |
| 章节照片不足 | 保留章节开场和说明页，提示添加照片；不以占位宠物图填充。 |
| 页面无图片 | 注记页可保留；照片页提示添加照片或删除页面。 |
| 相册权限受限/资产缺失 | 标识受影响照片，提供“Manage photo access”“Replace”；导出检查阻断。 |
| 内存/大相册压力 | 缩略图优先、延迟加载、低清预览；导出阶段逐页请求高分辨率，显示进度。 |
| 自动排版无足够素材 | 显示建议，不虚构章节或照片。 |
| 用户取消购买 | 返回原预览页，编辑状态不变。 |
| 用户删除档案 | 二次确认；删除文档、布局、缩略图缓存、PDF、视频及索引，不触碰系统相册原图。 |

## 9. 隐私、权限与付费边界

### 9.1 隐私

- 预览、裁剪、模板滤镜、自动排版、PDF 渲染全部在设备端完成。
- 不保存原图副本；仅保存 PhotoKit `localIdentifier`、小尺寸缓存（如实现）、页面几何与用户文字。缓存必须随档案删除。
- 不上传宠物名、照片、地点、时间、用户备注、页面布局或敏感标记。
- 敏感、永不使用、隐藏时期的照片不能进入页面选择器、预览缓存和导出队列。

### 9.2 付费

- 商品为非消耗型 `tailor.life_archive.unlock`，标准价 `$19.99`；最终地区价格以 App Store Connect 为准。
- 免费：完整编辑、保存草稿、全册结构查看、6–8 页真实带水印预览。
- 付费：完整无水印 PDF、A4/US Letter 完整输出、后续重新导出；恢复购买可恢复权限。
- 不将图片编辑、删除、敏感保护、访问既有草稿设为付费项。
- 开发/测试环境可通过明确 Debug 配置绕过购买；Release 不得包含绕过路径。

## 10. 数据模型与接口约束

### 10.1 建议模型

| 实体 | 必须字段 |
| --- | --- |
| `MemoryBookDocument` | id、archiveID、style、pageSize、pages、schemaVersion、updatedAt、lastExportedAt |
| `MemoryBookPage` | id、kind、chapterID、order、styleOverride、elements、isLocked、createdBy |
| `MemoryBookElement` | 见 6.1；图片保存 `assetID`，文本保存 `text` 与 text style token |
| `PageStyle` | templateID、背景、边距、安全区、字体 token、滤镜、装饰规则、水印规则 |
| `EditorHistory`（内存） | undo/redo 事务、时间、影响对象；默认不跨冷启动持久化 |
| `ExportRecord` | document snapshot hash、PDF 本地路径、页数、纸张、生成时间、是否水印、失败原因（如有） |

### 10.2 兼容与迁移

- 现有无 `elements` 的 `MemoryBookPage` 进入编辑器时，由旧的章节/照片字段生成一次默认元素，再写入新 schema；不得覆盖用户已有标题、章节顺序、封面或样式。
- 新增字段必须提供默认值，旧草稿解码失败时以只读恢复/迁移提示兜底，不可静默丢弃整本相册。
- PDF 重新导出始终使用当前 `schemaVersion` 的冻结快照；旧 PDF 不做原地修改。

## 11. 埋点（仅本地匿名漏斗）

所有事件仅记录本地匿名计数/时间，不得包含宠物名、照片 ID、缩略图、日期、地点、文字内容、敏感状态或任何布局坐标。

| 事件 | 触发 | 建议属性（允许范围） |
| --- | --- | --- |
| `editor_opened` | 编辑器成功加载 | `document_exists`, `page_count_bucket`, `style_id` |
| `editor_action` | 完成一次图片/文字/页面操作 | `action_type`, `page_kind`, `source(auto/user)` |
| `auto_arrange_requested/completed` | 自动排版 | `scope`, `affected_pages_bucket`, `result` |
| `book_check_completed` | 检查完成 | `blocking_issue_type`, `issue_count_bucket` |
| `preview_opened` | 进入预览 | `watermarked`, `page_count_bucket` |
| `export_started/completed/failed` | 导出生命周期 | `paper_size`, `watermarked`, `page_count_bucket`, `failure_category` |
| `purchase_prompted/completed/restored` | 购买状态 | `entry_point`, `result` |

## 12. 验收标准

### 12.1 产品验收

1. 用户可以从时间线进入初始相册，看到由真实已选照片构成的封面、目录、章节和结尾；不存在虚构照片或自动情感文案。
2. 用户可以为图片执行添加、替换、删除、拖动、缩放、裁剪、旋转、层级调整；可以编辑允许的标题和备注。
3. 用户的手动调整在切换模板、离开再进入、创建预览后仍保留；自动排版不改变锁定元素。
4. 用户可管理页面、新增/复制/删除照片页并在允许范围内重排；结构固定页不能被破坏。
5. 5 套模板可作用于预览和 PDF；Cinema/Film Album 是本地视觉滤镜/边框，不改变源图片。
6. 未购买只能导出/查看规定的带水印样章；购买成功或恢复购买后可完整无水印导出，取消/失败不丢草稿。
7. 档案中可找回最近导出的 PDF，删除档案后 PDF 和编辑数据不再可访问。

### 12.2 工程与视觉验收

1. 已保存的每一页在预览与 PDF 的位置、页序、照片、裁剪、文字和模板一致，满足 7.3 容差。
2. A4、US Letter、所有模板、单图/双图/拼贴/注记页均逐页比对通过；无黑页、透明页、空白异常页、重复页或图层错序。
3. 1、2、4、6 张照片及超过 6 张自动分页场景中，所有可入册照片正确显示，未选/敏感/隐藏/永不使用照片均不泄露。
4. 无网络、切后台恢复、低内存、权限变更、资产删除、导出失败和购买失败均保留可恢复草稿。
5. 编辑器在 20、100、500 张可入册照片下可进入、翻页、编辑和导出；具体性能阈值由技术评审补充，不得以主线程阻塞方式加载全尺寸照片。

## 14. 开放问题（评审门禁）

| 编号 | 问题 | Owner | 决策前影响 |
| --- | --- | --- | --- |
| OQ-01 | 文本能否自由拖动，还是只在模板安全区/预设锚点移动？ | 产品 + 设计 | 影响小屏可用性、PDF 文本测量和交互复杂度。v1 建议安全区内移动。 |
| OQ-02 | 每套模板是否允许单页覆写，还是必须全册统一？ | 设计 + 产品 | 影响 `PageStyle` 数据模型与成品一致性。v1 建议支持单页覆写但默认全册统一。 |
| OQ-03 | 是否允许用户手动添加同一张照片到多页？ | 产品 | 影响重复提示与自动排版。v1 建议允许，自动排版不重复。 |
| OQ-04 | PDF 是否须达到特定印刷规范（例如最小有效分辨率）？ | 产品 + 技术 | 决定图片请求规格、文件大小、导出时长。 |

| OQ-07 | 相册编辑器首发是否仅英语，宠物名支持中文等 Unicode 吗？ | 产品 + 本地化 | 文本截断、字体回退和 PDF 视觉验收依赖此决定。 |

## 15. 进入设计与研发的门禁

在开始高保真原型和正式编码前，必须完成：

1. 设计提供 E01–E09 全量画板，含选中、裁剪、文本溢出、空态、检查错误、购买失败、资产缺失和导出失败状态。
2. 设计定义每套模板的 `PageStyle` token、纸张安全区、可编辑锚点、字体和图片裁剪规则，不能只给静态效果图。
3. 工程完成 `MemoryBookDocument` schema、旧草稿迁移策略、SwiftUI/PDF 共享渲染 API 的技术设计评审。
4. 测试基于本 PRD 建立页面编辑、保存恢复、PDF 像素比对、权限/资产异常和购买边界用例，准备真机相册测试素材。
5. 产品、设计、研发、测试共同签署“预览即成品”的验收口径（第 7.3 节），没有该口径不得把 PDF 标记为可发布。
